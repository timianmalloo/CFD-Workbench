Quick reference

    
The whole language on one screen. Stations are distances from the center line; every spanwise quantity is a curve.

    

      
Stations

        center y = 0
tip y = b/2
225 mm or cm, m
50 % of half span

      
Curve modes

        linear corners, C⁰
smooth Catmull-Rom, may overshoot
monotone never overshoots —
each drop/rise is the extreme

      
Out-of-plane values

        level z = 0
drop 16 mm z = −16
rise 46 mm z = +46
bank true|false

      
Sections

        naca 4412 12% @ 30%, 4% @ 40%
naca 0012-64 peak moved to 40%

        profile { thickness 10% at 33%
  camber 2% at 40% }

      
Planform

        leading <mode> { at … x … }
trailing <mode> { … }
chord elliptic center 132
  taper 0.2 sweep 3 deg

      
Derived, never authored

        chord x_TE − x_LE
taper λ c_tip / c₀
Γ(y) atan z′(y)
turns, zeros, inflections

    

  


  

    
Grammar (EBNF)

    
Every choice is decided by the next token, so a recursive-descent parser needs no backtracking.

    

  


  

    
Static semantics

    
A program that parses is accepted only if it satisfies every rule. The first failure is reported with its line.
