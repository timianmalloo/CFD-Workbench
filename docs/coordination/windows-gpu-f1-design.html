# Windows GPU F1 design coordination plan

## Authority and goal state

**Goal:** produce the exact design package authorized by Ruling 211 for PETSc built `--with-cuda` plus
`petsc4Foam` against installed OpenFOAM 2512 on this Windows/WSL GPU host.

**Done when:** a source-cited design fixes the exact bill of materials and build plan, managed-memory measurements,
CPU-vs-GPU benchmark contract, and observer/guard; an independent Astra review records ACCEPT or VETO; and the
reviewed package reaches the Mac leader through GitHub for Fable review and a second operator ruling.

**Not in scope:** package or build-input download, installation, build, case execution, mutation of
`cfdw-openfoam2512`, or a GPU speed-up claim.

**Authority quote:** “No install, build or download of build inputs beyond read-only metadata until a second operator
ruling approves the plan.” — `docs/notes/rulings.md`, Ruling 211.

**Tier:** T1. **Maximum parallel width:** 1. The bill of materials constrains the measurement contract, benchmark,
guard, capacity budget, and rollback. One author owns that coupled decision; independent review follows serially.

## Intent and surface list

## Seams

| from -> to | the request | resolved by |
|---|---|---|
| Coordinator → AUTHOR | Produce one closed design from repository evidence and read-only authoritative metadata. | AUTHOR commits the design and evidence; unresolved compatibility is a blocker. |
| AUTHOR → ASTRA | Review an immutable commit against every Ruling 211 obligation and hard veto. | ASTRA records ACCEPT or VETO without editing the design. |
| ASTRA → REVIEW | Decide whether the package is complete enough for operator review. | Mac/Fable records an independent review in GitHub and the repository. |
| REVIEW → operator | Request only the exact next action in the accepted plan. | Mac records the operator ruling; until then execution remains closed. |

Each track uses an isolated worktree from the preceding joined commit. The coordinator validates each authored diff and
joins it with `conductor-join.py --epoch 2`. A different current epoch is a stale-plan stop, never an implicit adoption.
Docs-only joins print `RING-SKIPPED`; the required fast documentation gates and readiness check still run at the final
head. GitHub is the cross-host convergence record.

The scan guards are jointly satisfiable. AUTHOR may recurse from repository root only through `docs/`, `cases/`, and
read-only online metadata; its token set is the Ruling 211 component, benchmark, measurement, and guard vocabulary; its
write allowlist is exactly its two owned paths. ASTRA may recurse through the frozen AUTHOR diff and cited repository
evidence; its token set is the hard-veto checklist; its write allowlist is its one review file. REVIEW reads the joined
GitHub revision and writes only its review and Mac-owned ruling paths.

The coordination multiplier is bounded to one delegate at a time. AUTHOR earns isolation and context hygiene for a
large source-closure task; ASTRA earns independent adversarial review. No machine-time parallelism is claimed.
