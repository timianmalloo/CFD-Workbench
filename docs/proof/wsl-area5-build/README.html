2. Verified net.proxy-tls network blocker (OpenFOAM repo)

Running tools/wsl-preflight.sh --keyrings /mnt/d/reviewed --out /root/cfdw-receipts/preflight-receipt.json on the fresh distro exited 1 at step=update in 11 s (preflight-receipt.json). Direct diagnosis (net-proxy-tls-receipt.json) verified:

  1. https://dl.openfoam.com/repos/deb/dists/noble/InRelease itself completes TLS cleanly (dl.openfoam.com) and returns

HTTP/2 302 with location: https://sourceforge.net/projects/openfoam/files/repos/deb/dists/noble/InRelease.

  1. On this network, DNS resolves sourceforge.net to ::ffff:146.112.61.104 (Cisco Umbrella / OpenDNS).
  2. openssl s_client inside WSL observes issuer=O = Cisco, CN = Cisco Umbrella Secondary SubCA lax-SG with

Verify return code: 20 (unable to get local issuer certificate).

  1. apt-get update fails closed with Certificate verification failed: The certificate is NOT trusted. The certificate issuer is unknown.
  2. Native Windows curl.exe fails closed identically with

curl: (60) schannel: SEC_E_UNTRUSTED_ROOT (0x80090325) - The certificate chain was issued by an authority that is not trusted.

No TLS verification bypass, DNS override, or proxy circumvention was attempted. Meanwhile, ports.ubuntu.com, developer.download.nvidia.com, web.cels.anl.gov, and gitlab.com all verified cleanly over TLS.   • Two real environment findings captured into `tools/wsl-build-openfoam-cuda.sh`:
  1. Installing gcc-13, g++-13, gfortran-13 without the unversioned gfortran meta-package leaves mpif90 unable to

5. Resuming OpenFOAM v2512 + petsc4Foam on an unfiltered network

The dedicated distro cfdw-openfoam2512-arm64 already holds the installed CUDA 13.2 + GCC-13/OpenMPI toolchain, built PETSc 3.26.0 (arch-linux-cuda132-opt), and staged petsc4Foam commit cb1badc4978306e7001a4654dcdf53f284a92365 (tree 74e5dbf216effe0768687dec8e66c56f79c9df85). Once connected to a network where sourceforge.net is not TLS-filtered:

wsl.exe -d cfdw-openfoam2512-arm64 -u root -- bash <repo-wsl-path>/tools/wsl-build-openfoam-cuda.sh \
    --mode openfoam-resume --keyrings /mnt/d/reviewed --receipt-dir /root/cfdw-receipts

This adds the verified OpenCFD apt repo (openfoam-archive-keyring.gpg, gpgv VALIDSIG), installs the five pinned openfoam2512*=2512.0-2 packages (with zero removals and zero Linux GPU driver), runs the Ruling 133 M1 icoFoam/cavity CPU smoke (allowSystemOperations 0, t=0.5, expected Courant mean 0.222158), compiles petsc4Foam via ./Allwmake, and checks foamHasLibrary -verbose petscFoam.
