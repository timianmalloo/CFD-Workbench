4. TypedCaseModel & Dual Deterministic Emitters (C2, M1–M8)

4.1 TypedCaseModel (one model, two emitters)

TypedCaseModel is an immutable Core record representing a single CFD case:

  • Geometry & reference inputs: RunInputs (AcceptedId, SurfaceHash, ProfileHashes, Evaluator, PlacementRule), RunReference (SRef, BRef, CRef, MomentDatum, Axes), TeFloorMm (for blunted-TE disclosure if applicable), wing bounding box (MinBounds, MaxBounds).
  • Fluid & operating point: WaterRecord (validated 0–50 °C, 0 or 35.16504 g/kg, pinned ITTC table hash), OperatingPoint (Speed > 0, PAtm > 0, HRef?, Datum, AlphaDeg).
  • $\alpha$ imposition by inflow direction (spec A5.10:1124):

$$\mathbf{U}_\infty = \bigl(V \cos\alpha,\; 0,\; V \sin\alpha\bigr), \quad \hat{\mathbf{d}}_{\text{lift}} = (-\sin\alpha,\; 0,\; \cos\alpha), \quad \hat{\mathbf{d}}_{\text{drag}} = (\cos\alpha,\; 0,\; \sin\alpha)$$ Because the wing mesh stays fixed in body axes (+x aft, +y starboard, +z up) and only the inflow vector rotates with $\alpha$, one mesh serves every $\alpha$ at a held geometry and speed. 5.2 Wall-function feasibility check (DR-F2-3)

Before admitting WallTreatment.WallFunction, TypedCaseModel.CheckWallFunctionFeasibility estimates the turbulent boundary-layer thickness at the reference chord $c_{\text{ref}}$ and highest speed $V_{\max}$:

$$Re_c = \frac{V_{\max}\,c_{\text{ref}}}{\nu}, \qquad C_f \approx 0.058\,Re_c^{-0.2}, \qquad u_\tau = V_{\max}\sqrt{\frac{C_f}{2}}, \qquad \delta \approx 0.37\,c_{\text{ref}}\,Re_c^{-0.2}$$

The first cell centre at $y^+ = 30$ sits at $y_1 = 30\,\nu / u_\tau$; with 15 points expanding at $r \le 1.2$ (starting step $\Delta y_1 = 2\,y_1$), the required layer stack thickness is:

$$H_{15} = \Delta y_1\,\frac{r^{15} - 1}{r - 1}$$

Wall-function mode is admitted iff $H_{15} \le \delta$ (so $\ge 15$ points with $y^+ \ge 30$ fit inside the estimated turbulent boundary layer over the chord). At typical hydrofoil $Re_c \sim 5\times 10^5$, $H_{15} > \delta$, so the check honestly refuses wall functions and directs the case to the wall-resolved branch ($y^+ \le 1$).

6.2 DR-F2-1 three-part residual criterion (Ruling 65)

CfdRunStateMachine.EvaluateResiduals(ResidualWindowInput) checks all three required parts:

  1. Initial residual drop ($\le 10^{-3}$): For every solved equation $e$ (e.g., p, Ux, Uy, Uz, nuTilda or

k/omega), $r_{e,\text{final}} / r_{e,\text{first}} \le 10^{-3}$ (three orders of magnitude, ITTC). If $r_{e,\text{first}} \le 0$ or non-finite, the check fails closed (CFD-RESIDUAL-INVALID).

  1. $C_L$ and $C_D$ stationarity over averaging window: Over the final $W$ iterations (minimum $W \ge 20$), compute

half-bands $U_{I,C_L} = \frac{1}{2}(\max C_L - \min C_L)$ and $U_{I,C_D} = \frac{1}{2}(\max C_D - \min C_D)$. Pass iff $U_{I,C_L} \le \epsilon_{C_L}$ and $U_{I,C_D} \le \epsilon_{C_D}$. The reported force coefficients are the arithmetic window means $\overline{C}_L, \overline{C}_D, \overline{C}_m$.

  1. Clean turbulence window: Zero bounding events of the turbulence variable (bounding nuTilda for SA; bounding k

or bounding omega for SST) inside the averaging window (TurbulenceBoundingCountInWindow == 0).

If the solver reaches MaxIterations with valid outputs but ANY of parts 1–3 fails, Harvesting transitions to CompletedResidualNotMet ("Completed — residual criterion not met (ran to limit)") — never Completed with a Converged label.

6.3 LAB-01 three-part Converged label (spec A7:1295)

CfdRunStateMachine.FormatConvergedLabel(ResidualSummary summary, bool outputsComplete):

  • Returns null unless outputsComplete == true && summary.CriterionMet == true.
  • When both hold, returns the exact three-part fixed string:
  Converged: residuals <= <r> · outputs complete · grid uncertainty not quantified (single mesh)

where <r> is formatted invariant-culture scientific notation (e.g., 4.2e-04) of summary.MaxInitialResidualRatio.

  • Part 3 ALWAYS reads grid uncertainty not quantified (single mesh) in v1 (no three-grid study Experiment kind

exists in v1). A dedicated LAB-01 lint check verifies that "Converged" never appears in Area 5/6 copy or projections without all three parts.
