# PR #27 — Fable owner review

PR #27 "docs(proof): retain blocked COPY-447 reachability capture" (origin/win/copy447-measurement, head 5579dea6, proof
commit 0ed7a1b5) was reviewed by the Fable owner on the Mac on 2026-10-09 under Ruling 106. Verdict: **APPROVE WITH
CONDITIONS**, issued as **Ruling 190**. Each finding is Verified unless marked Inferred.

## Findings

1. **The receipt is honest within its limits.**
   - create-only: before `[]`, after `[]`, target absent (`capture/create-only.stdout.txt`).
   - overwrite: before and after each hold the 30-byte `project.cfdw` with the same SHA, and `unchangedFromBefore: true`.
   - The inventory is self-tested against a known-file oracle.
   - `SaveAsync` calls `Supported()` first (`ProjectStore.cs:76`, `:103`), which requires macOS arm64 (`:266-270`). So
     Windows never reaches a filesystem stage, and NOT ASSESSED is the only correct conclusion.
2. **The exits were observed and then lost.** `capture.ps1` used the committed runner (`:21-22`, `Invoke-WriChild` at
   `:28`, `:35`, `:50`, `:120`). The runner returned numeric exits, PHN and raw hashes in memory (`:71-81`), but
   `capture.ps1` deferred all of them to one final `receipt.json` (`:124-147`). With `$ErrorActionPreference='Stop'` and no
   catch, a throw lost them and the launcher's own error. This is a sibling of WINDOWS-CAPTURE-LIFECYCLE: the exit was
   lost by write order, not by a watchdog. `package-pii.ps1:34-59` does it right.
3. **Packaging overwrote originals.** `package-pii.ps1:34-35` overwrote `pii.stdout.txt` and `pii.stderr.txt`, destroying
   the one artifact that could have shown how far the capture got.
4. The recorded `py -3` command is a description, not the executed argv. The receipt discloses this. Minor.
5. **Inferred:** both case children exited 0 with PHN passing (`windows-runner.ps1:276` withholds text on PHN failure).
   It is not promoted; the receipt says "not recorded".
6. **Live-path bindings that already existed, not from this PR:** `win-naca` manifests bind `cases/*.yaml`, which is by
   design, and `win-routes/manifest.json` binds `cases/*.yaml` and `docs/design/guided-solver-setup.md`. The second is a
   live design document (CLOSING-MANIFEST-MUTABLE-PATH).

Gates on the PR head (main is already merged into it), all exit 0:
