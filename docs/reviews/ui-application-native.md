## Scope and method

The affected chain is accepted FoilDSL bytes → core-owned draft/assessment →
accepted identity and history → native image/store → controller → visual and
accessible views, with CLI consuming the same core. The bounded C milestone
allows an independent numeric LE/TE control edit and sparse certified points;
it is not the complete v7 section-profile editor or a simulation implementation.

Root freezes compiled worker checkpoints in separate scratch directories and
uses independently written consumer programs and actual CLI subprocesses.
Each later consumer disables implicit MSBuild item discovery and asserts runtime
assembly hashes before launch. Local .NET/NuGet/temp roots and observed PID/start
identities bound these runs; this is observed containment, not a sandbox claim.
Retained raw receipts live under `/tmp/cfd-adapter-review.3sSb4H` and
`/tmp/cfd-controller-review.B2SeOB`. They are local evidence, not portable product
assets. The descriptions and fingerprints below remain reviewable without them.
