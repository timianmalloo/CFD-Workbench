## Findings

1. **This is not the run.** `windows-runner.ps1:327-341` has one entry point, `Ready`. It prints
   `RUNNER_READY … scale_change=false contract_execution=false`. No UIA select, no test invocation and no restore exist in
   the four files.
2. **The root wait is half the child ceiling** (`:173-176`). At the default 60 s, the product child gets at most 30 s.
   PR #21's build took 24.9 s (`r177-build.measurement.txt:3`). This is a trap for the driver, not a library defect.
3. **(a)** No AppliedDPI, registry, DateTime or UtcNow token appears (`check-windows-runner.py:192`; mutant 1). The check is
   lexical: a `reg.exe` call would pass (Inferred, minor).
4. **(b)** The preflight is read-only (`windows-settings-preflight.ps1`). `Assert-WriSettingsState` (`runner.ps1:315-320`)
   throws unless the state is exact. Red: fixtures with Settings closed or collapsed, and an absent-frame flag. Mutants 2–5
   and 17–19 hit the allowlists.
   - Limit: the live UIA path (`:10`) is not exercised by a test.
   - Limit: the `150%` equality blocks reuse during the restore leg.
5. **(c)** `Wait-WriDeadline` (`:87-94`) copies `capture-calibration.ps1:13-21`. The 899,750 / 900,000 ms probe, the
   real-process timeouts and mutants 7, 8, 13 and 14 cover it. There is no parsed instant.
6. **(d)** `Assert-WriToolchain` (`:286-314`) checks dotnet by full path, the `sdk/10.0.203` folder and `--version`, and
   Python by absolute path, confirmed against its own `sys.executable`. This is stronger than `capture.ps1`.
7. **(e)** Children launch suspended and join a job before they resume. The handle is retained. `Assert-WriNumericExit`
   checks the exit. Stubs exiting 0 and 3 return numeric codes. The Ruling 181 order (build-server shutdown, then the
   residual query) is asserted.
8. **(f)** A `git diff --quiet` check, an untracked-file check and SHA-256 fingerprints run before and after
   (`:102-123`). Red: a one-byte edit and an untracked file. Gap: `global.json` and `CFDWorkbench.slnx` are outside the
   guard.
9. **The mutants.** None is false-green. All 19 fire for their own control. The anchor check (`:263-265`) closes the
   repair-1 false-green class. The policy covers only two files (`:28-29`), so a driver would be unguarded.
10. **Reuse.** The deadline and toolchain checks are adapted copies. That is acceptable, because their self-test is at
    least as strong.
11. **The MSP prints are on main.** The runner records nothing about the 14 checks yet.
12. **Ruling 183.** The red and green captures and both hashes are recorded. That the gates ran before the freeze is
    Inferred from the durations: the JSON files carry no timestamps.
