- **[Blocker] (Verified) A2 S5 release boundary says "One validated single-phase case on each supported platform" (l.60) — "validated" is the ITTC/ASME word for |E| < U_V against experiment, and no dataset, comparability or U_V is named.** evidence: spec l.60; H-17; 13 H-4 (validation = E = D − S vs U_V² = U_D² + U_SN²); 13 H-13 (TMR NACA 0012 is a *verification* case in air, not a water hydrofoil validation). fix: S5 gate reads "one *verified* single-phase case per platform: TMR NACA 0012 (fully turbulent → Ladson *tripped* data; transition model → *untripped* data, never crosswise), three-grid ITTC 7.5-03-01-01 Rev 05 study with reported U_G, harvested coefficients reconciling to forces within declared tolerance". Reserve "validated" for A6's Experimentally-compared label.

- **[Blocker] (Verified) The "converged" label has no definition anywhere in the spec.** "convergence evidence" (l.189), "unavailable convergence" (ANA-04 l.229), "declared convergence and output checks" (B5 l.439) are used, but no criterion, no artifact oracle and no grid-uncertainty statement are specified; a sweep sample state is "Complete" (l.189) with nothing that distinguishes Complete from Converged. evidence: 08 impl 11 (three-part label); 08 §Data "Invariants" (2): Converged only if criterion fired *and* artefact oracle passed; "Single mesh" until grid study; 08 H-5 (≥ 3-order scaled-residual drop, force convergence fallback); 08 H-6. fix: add to A3 (Analysis run / Sweep) and a new CFD-07: "Converged" is a three-part label — residual criterion (named, with the drop achieved) · artifact oracle (named files present and consistent) · grid uncertainty either `U_G = x % (ITTC 7.5-03-01-01 Rev 05, n grids, r)` or the literal `Not quantified (single mesh)`. A sample may be Complete-but-not-converged; the UI shows both. A Sweep never displays a grid uncertainty it did not compute.

- **[Blocker] (Verified) A6 "Experimentally compared" (l.266–268) lacks its evidence triple.** The text says "requires a comparable configuration and uncertainty/source review" but names no dataset id field, no comparability enum, no E ± U_V readout, and no priority list of admissible datasets. evidence: KB-10; 13 impl 1–2 (dataset id · configuration comparability wing-only/foil+strut/near-surface · E and U_V or "U_D not stated by source"); H-21 (Day 2019 foil+strut, TR-1232 near-surface, ADA032272 foil-system); 13 failure mode "comparing wing-only coefficients with foil+strut lift areas". fix: A6 label rule: Experimentally compared = {dataset id + hash, configuration class ∈ {wing-only, foil+strut, near-surface, foil-system}, E = D − S, U_V or "U_D not stated by source", phrase "validated at the U_V level" only when |E| < U_V}. Add the validation dataset register in priority order (Day 2019 → TR-1232 → CEHINAV 2026 → TMR NACA 0012 (backend verification) → ADA032272) as provenance-carrying fixtures under the ANA-09 hashing rule. Also adopt 13 impl 7: when tiers disagree, the recommended value is the highest tier whose uncertainty is *reported*, never the lowest number.

- **[Blocker] (Verified) A6 "Verified numerical implementation" (l.266) has no fixture-suite definition; A7 Maintainability (l.284) names only "signs, units, stale results and conversions".** No analytic reference, metamorphic invariant, observed-order test or both-OS ring-0 runner is a stated requirement. evidence: KB-10; KB-23; 13 impl 8–9 (manufactured geometries with closed-form area/centroid/inertia; observed-order on station refinement; knot-insertion exactness; thin-airfoil and Joukowski oracles; elliptic-wing e = 1 at rel 1 % CL / 5 % CDi proposed; NACA 0012 TMR with GCI for any RANS backend; DAT fixtures both layouts; both-OS ring 0). fix: new A7 row "Numerical verification floor" enumerating the per-method suite exactly as KB-23, with "observed red before green" for every fixture, and the rule that the label is granted per method by that suite in CI, never by a hash match (the spec already says hashes do not close gaps, l.268 — make it mechanical).

- **[Blocker] (Verified) CLI-01 (l.262) "agree to the operation's published tolerance" — no tolerance table exists, and DOC-02 (l.206) promises 1 µm "on either platform" without saying whether the comparison is over re-evaluated surfaces or bytes, or whether any bitwise claim is intended.** The A4 surface applies a twist *rotation* (l.169) — sin/cos — so bitwise cross-platform equality of evaluated geometry is impossible by construction. evidence: H-22 / KB-22 (bitwise only for + − × ÷ √ FMA; .NET `Math.Sin` and Rust transcendentals platform-dependent); 13 impl 10 (bitwise restricted to + − × ÷ √ FMA after an FMA-contraction spike; relative 1e-12 for anything transcendental; golden masters stored with platform, runtime version, commit; both-OS ring 0); 05 impl 6 (DOC-02's 1 µm is an *evaluation* tolerance — compare surfaces, serialisation contributes 0); KB-1 (identity = 1 µm absolute *and* 10⁻⁶ relative). fix: CLI-01 carries a per-operation table: measure/estimate (geometry evaluation) — abs 1 µm and rel 1e-6 on re-evaluated surfaces; section/wing (transcendental paths) — rel 1e-12 on stored golden masters with platform + runtime + commit provenance; never bitwise for any operation that calls libm. - **[Major] (Verified) CFD-03 (l.246) "the process tree terminates" and CFD-06 (l.249) "cancels active processes" do not reach the substrate the run actually lives in; the spec never names Docker/WSL.** evidence: H-20 (`Process.Kill(entireProcessTree)` silently skips uninspectable processes; neither .NET nor CliWrap reaches inside a container or WSL distro); 08 impl 8 (run-id as `docker --name` / WSL process-group marker / case path; Cancel = substrate kill → host tree kill → bounded wait → orphan scan → Cancelled with partial outputs); 08 failure mode "killing the host client and leaving a container writing into the case directory the user then edits". fix: CFD-03/06: cancellation is addressed to the substrate by run-id; the Cancelled state is granted only after an orphan scan inside the substrate reports none; a timed-out kill is a visible error (A7 Reliability already allows the error — make the orphan scan the evidence). ## TIGHTEN:

1. **"validated" (A2 S5, l.60)** — used for a verification gate; reserve for ITTC validation (|E| < U_V). Two meanings in one document.
2. **"Complete" vs "Converged" (l.189, l.246, l.439)** — Complete is an artifact-oracle state; Converged is the three-part label; the spec conflates "declared convergence and output checks" into one sentence. Define both; a sample can be Complete and Not converged.
3. **"convergence evidence" (l.189) / "unavailable convergence" (l.229)** — not falsifiable until the criterion is named per method (residual drop for RANS; panel/station refinement order for VLM/strip).
4. **CFD-02 "failed mesh-quality threshold … with the failed measure"** — not falsifiable without the measure list and thresholds; name them and label their source.
5. **CFD-03 "process tree terminates"** — falsifiable only on the host; the substrate is where the solver lives. Rewrite as "the run-id is absent from the substrate after an orphan scan".
6. **CFD-03 "a zero exit code without required outputs is not success"** — "required outputs" undefined; enumerate per backend.
7. **CLI-01 "operation's published tolerance"** — published where? Put the table in the spec; no bitwise claim beyond + − × ÷ √ FMA.
8. **DOC-02 "within 1 µm model-space geometric tolerance" on "either platform"** — say "re-evaluated surfaces, abs 1 µm and rel 10⁻⁶"; JSON text equality is not the test; the twist rotation is transcendental, so bitwise is impossible and must not be implied.
9. **GEO-06 / GEO-11 "no more than 1 µm"** — add the relative 10⁻⁶ term (KB-1) so a 1.4 m span and a 20 mm tip chord are held to the same rule.
10. **A6 "Experimentally compared … requires a comparable configuration and uncertainty/source review"** — "review" is not evidence; require the fields (dataset id, configuration class, E, U_V).
11. **A6 "Verified numerical implementation … require their specific proof"** — name the proof (the fixture suite per method, observed red first, both OSes).
12. **A7 Reliability "process shutdown ≤ 5 s or visible timed-out termination error"** — the 5 s is unsourced (Flagged) and the error must include the substrate orphan-scan result to be honest.
13. **A7 Compatibility "Supported backend versions are pinned"** — pinned by image digest / release-asset hash, never a floating tag (08 invariant 6).
14. **A7 Safety row** — "limitations appear at relevant decision/export points" is tone; make it the three fixed strings with the regulatory basis, tested as rendered content.
15. **A2 "No fabrication or structural safety certification is implied"** — add "and no strength, stiffness, fatigue, impact or ride-safety statement is rendered without a named model, load case and reserve factor (none exist in v1)".
16. **ANA-11 "Structural adequacy is not inferred from loads"** — a rendered `Not assessed` state, not a sentence; and reconcile lift/moment, not only drag; name the root-moment datum and axis.
17. **ANA-11 "root bending moment (N·m)"** — steady, n = 1, about the root plane; say so and list the load cases not assessed.
18. **A4 "Manufacturing assessed requires an explicit manufacturing policy"** — in v1 no policy object exists, so "Manufacturing assessed" is never rendered; only "TE floor: checked against <preset> (practitioner value, unverified)" is.

20. **A4 "open/sharp/finite-thickness trailing-edge … supported by the exporter"** — "sharp" is unbuildable as drawn on every route in the KB; couple it to the floor finding in every geometric export.

22. **EXP-02 "section DAT, mesh, STEP or chart export"** — "mesh" has two meanings (print vs CFD) with different units; split them.
